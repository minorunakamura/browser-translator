# Issue tracker

## Tracker

GitHub Issues（github.com / minorunakamura/browser-translator）

## 保存・取得

- 作成: gh issue create --repo minorunakamura/browser-translator
- 取得: gh issue view <番号> --repo minorunakamura/browser-translator
- ラベル: ready-for-agent

## 依存関係

本文の Blocked by に blocker の Issue の実リンクを記す。利用できれば native の blocking relationship も設定する。
